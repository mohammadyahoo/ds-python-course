# Data Science with Python: course website

Teknova training course by Mohammad Labania. 40 sessions of 90 minutes in 2 levels and 6 stages.

This repository is a static website. For every session it offers the slide deck (PPTX and PDF),
the lecture, exercises and solutions notebooks with an "Open in Colab" button, and three ready
messages for the student group: before the session, the homework, and the homework solution.

- Website: https://mohammadyahoo.github.io/ds-python-course/
- Materials: `materials/SNN-slug/`
- Practice data: `data/` (the notebooks read it from this repository)
- Hosting instructions: `HOSTING.md`

The repository must stay **public** so that Colab links and the data URL work for students.
